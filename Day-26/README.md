# React API Projects

## Crypto Tracker
React/Vite cryptocurrency tracker using CoinGecko market data. It refreshes every 30 seconds.

## News App
React/Vite news reader using NewsAPI through a Vercel serverless function. Add NEWS_API_KEY to Vercel Environment Variables before deploying.

Each folder can be deployed as a separate Vercel project by importing the repository and setting Root Directory to the selected folder.
