# Fuli Eliot Nchongtakang Portfolio

React + Vite portfolio with React Router navigation for Home, About, Projects and Contact.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

The project uses HashRouter so it can be deployed safely as a static site on GitHub Pages. Build the project and publish the `dist` folder.

Replace the placeholder email and social URLs in `src/pages/Contact.jsx`, and add your actual project GitHub/demo links in `src/pages/Projects.jsx`.

Add a personal photo by replacing the `YOUR PHOTO` area in `src/pages/Home.jsx` with an image from `public/`.
