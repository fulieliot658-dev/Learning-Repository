# Fuli Eliot Portfolio

React + Vite + React Router portfolio. Live project buttons use Vercel URLs only.

To add a newly hosted project, edit `src/data/projects.js`, copy a project line, change its title/details, and paste the new Vercel URL into `vercelUrl`.

If this portfolio is placed inside `Learning-Repository/portfolio`, set the Vercel Root Directory to `portfolio`.

For each learning project, create a separate Vercel Project from the same GitHub repository and set Root Directory to the exact folder containing that project, such as `Day-13`, `my-first-app`, or `Day_9/tic-website`.
